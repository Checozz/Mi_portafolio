# Desarrollo Full Stack

Construyo aplicaciones end-to-end, desde la base de datos hasta la UI. Mis stacks favoritos combinan **Firebase** (backend rápido + auth + Firestore) con **Flutter** o **Kotlin** para móvil, y **GCP** cuando algo necesita escalar.

## Lo que disfruto

- Diseñar esquemas de Firestore que escalen sin re-arquitectura
- Trabajar con auth flows reales (no solo "login con email")
- Animaciones nativas en Flutter que se sienten fluidas
- Deployment automatizado vía Cloud Build / Firebase Hosting

## Filosofía

Ser **full stack** no es saber un poco de todo: es entender cómo cada capa afecta a las demás. Una mala query en el backend mata la UX por más bonita que esté la pantalla.

## Stack

`Kotlin` · `Flutter / Dart` · `Firebase` · `Firestore` · `GCP` · `Cloud Functions` · `MongoDB`
